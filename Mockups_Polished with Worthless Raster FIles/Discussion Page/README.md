# Which Game Used — Discussion Page Asset Package

## Package contents
This ZIP contains the current **Discussion** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — key reference images used during iteration
- `cropped_sections/` — major UI section crops
- `topic_rows/` — visible discussion topic row crops
- `thread_rows/` — visible active thread row crops
- `icon_illustration_crops/` — isolated crops of the main illustration and notable icon areas

## Mockup summary
The **Discussion** page is the forum hub for the hobby community. Users can follow topics, browse active threads, and participate in conversation around authentication, counterfeits, hobby history, and research questions.
