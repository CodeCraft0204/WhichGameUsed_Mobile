# Which Game Used — Leaderboard Page Asset Package

## Package contents
This ZIP contains the current **Leaderboard** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — palette and related style reference images used during iteration
- `cropped_sections/` — major UI section crops
- `content_rows/` — visible leaderboard row crops (#1 through #5)
- `icon_illustration_crops/` — isolated crops of the main illustration and notable icon areas

## Mockup summary
The **Leaderboard** page is designed to show the top 20 users on the platform based on a points system. Placement reflects a user’s helpful participation and authentication-related research work, but the page displays only the final point totals rather than the underlying metrics.

## Palette notes
A palette reference image is included in `references/color_palette_reference.png`.
The page mockup uses a soft editorial neutral system built around:
- warm off-white / ivory backgrounds
- taupe / sand accent line and muted fills
- charcoal / black ink for interface text and icons
- light gold/bronze highlight accent for the active leaderboard nav state
- grayscale illustrations for a collectible-archive feel
