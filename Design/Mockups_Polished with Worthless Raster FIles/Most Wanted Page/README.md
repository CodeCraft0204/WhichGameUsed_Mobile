# Which Game Used — Most Wanted Page Asset Package

## Package contents
This ZIP contains the current **Most Wanted** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — palette and prior style reference images used during iteration
- `cropped_sections/` — major UI section crops
- `content_rows/` — visible ranking row crops (#1 through #5)
- `icon_illustration_crops/` — isolated crops of the main illustration and notable icon areas

## Mockup summary
The **Most Wanted** page is designed to show the cards the community most wants authenticated. It includes:
- ranked card entries
- likes, dislikes, and comments counts
- bounty callouts for evidence that helps authenticate a card
- category tabs for browsing by sport or view

## Final on-page tab labels

## Reward banner copy
- Heading: **WE REWARD REAL RESEARCH.**
- Supporting text: **Your evidence can earn sealed product, classic game-used cards, and cash.**

## Style notes
- Heading / display style: **Permanent Marker Regular**
- Subtitles / all-caps editorial accents: **Broadsheet Regular**
- Supporting UI and body text: rendered as a clean app-friendly supporting type style within the mockup

## Palette notes
A palette reference image is included in `references/color_palette_reference.png`.
The page mockup uses a soft editorial neutral system built around:
- warm off-white / ivory backgrounds
- taupe / sand accent line and muted fills
- charcoal / black ink for interface text and icons
- grayscale card illustrations for a collectible-archive feel
