# Which Game Used — Database Page Asset Package

## Package contents
This ZIP contains the current **Database** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — key reference images used during iteration
- `cropped_sections/` — major UI section crops
- `record_rows/` — visible featured/recent record row crops
- `icon_illustration_crops/` — isolated crops of the main illustration and notable icon areas

## Mockup summary
The **Database** page is designed as the searchable record archive for the app. It highlights authenticated cards, provenance notes, patch examples, and research evidence in a structured archive-style interface.
