# Which Game Used — Authentication Page Asset Package v2

## Package contents
This ZIP contains the updated **Authenticate** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — reference images used during iteration
- `cropped_sections/` — major UI section crops
- `submission_rows/` — visible draft submission row crops
- `scanned_rows/` — visible recently scanned row crops
- `icon_illustration_crops/` — isolated crops of the main illustration, CTA button, and notable icon areas

## Mockup summary
The **Authenticate** page is the submission-preparation area for users. The active view is the **SUBMISSIONS** tab, where users keep track of cards that have been scanned or drafted but not yet sent into the system.

## Final header copy
- Main title: **AUTHENTICATE**
- Subtitle: **SUBMIT YOUR CARDS WITHOUT SUBMITTING YOUR CARDS.**
- Supporting paragraph:
  “Scan your collection of game-used cards. If your card has been authenticated in our database, simply submit for authentication and we will mail you a tamper-proof QR-linked label for FREE.”
