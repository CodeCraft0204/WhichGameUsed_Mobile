# Which Game Used — Advocacy Page Asset Package

## Package contents
This ZIP contains the current **Advocacy** mobile page mockup and supporting extracted assets.

### Included folders
- `full_mockup/` — full exported page image
- `references/` — palette and prior style reference images used during iteration
- `cropped_sections/` — major UI section crops
- `petition_rows/` — visible petition card row crops
- `icon_illustration_crops/` — isolated crops of the main illustration and notable icon areas

## Mockup summary
The **Advocacy** page is designed to help users sign petitions that push for greater transparency in the game-used memorabilia card hobby. The page presents active petitions, current signature counts, visible goals, and clear call-to-action buttons.

## Final header copy
- Main title: **ADVOCACY**
- Subtitle: **MORE TRANSPARENCY. MORE TRUST. BETTER HOBBY.**
- Supporting paragraph:
  “Sign petitions, raise your voice, and push the hobby toward transparency. Together, we can ask manufacturers to share the records collectors deserve.”

## Style notes
- Heading / display style: **Permanent Marker Regular**
- Subtitles / all-caps editorial accents: **Broadsheet Regular**
- Supporting UI and body text: rendered as a clean app-friendly supporting type style within the mockup

## Palette notes
A palette reference image is included in `references/color_palette_reference.png`.
The page mockup uses a soft editorial neutral system built around:
- warm off-white / ivory backgrounds
- taupe / sand accent line and muted progress fills
- charcoal / black ink for interface text and icons
- subtle bronze / brown accent for the active Advocacy nav state
- grayscale sketch illustrations for a collectible-archive feel
