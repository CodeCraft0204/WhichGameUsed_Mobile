Broadsheet Regular (required for editorial accents)

Place your licensed Broadsheet Regular webfont files in this folder using one of these names:

  Broadsheet-Regular.woff2
  Broadsheet-Regular.woff
  Broadsheet-Regular.ttf

The page also checks for a locally installed "Broadsheet Regular" / "Broadsheet" font.

Sources: Adobe Fonts, MyFonts (Three Islands Press), or 3ipfonts.com
